# Сопроводительное письмо — AGIMA, стажёр AI-разработчик

Здравствуйте!

Меня заинтересовала стажировка в R&D-команде AGIMA. В разработке использую AI-инструменты и агентный подход: разбиваю задачу на небольшие этапы, задаю проектный контекст и ограничения, использую правила/skills и проверяю результат по реальному поведению приложения.

Для демонстрации подготовил портфолио с исходниками трёх прототипов:

- **RequestPilot** — интерфейс и FastAPI API для первичного разбора входящих заявок: категория, приоритет, краткое резюме и черновик ответа. В локальном режиме работает без внешнего API; предусмотрено подключение OpenAI-compatible LLM endpoint через серверные переменные окружения.
- **FurniQuote Bot** — прототип Telegram-бота на aiogram: пошаговый сбор параметров, валидация, предварительный расчёт и сохранение заявки в SQLite.
- **DataFlow Cleaner** — Python CLI для очистки CSV, удаления дублей и формирования JSON-отчёта.

Это демонстрационные прототипы, а не заявления о production-внедрениях у клиентов. Я могу показать запуск, объяснить логику и обсудить ограничения и следующие шаги развития.

В качестве coding harness использую **OpenCode** с LLM через **OpenRouter**. Он удобен мне тем, что позволяет работать с контекстом проекта, правилами и skills, поручать агенту ограниченные задачи и затем проверять изменения в коде. Также изучаю практики работы с контекстом, sub-agents и MCP; не хочу выдавать знакомство с инструментом за глубокий production-опыт.
